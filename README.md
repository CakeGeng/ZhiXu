**知序 v1.0.0——知序文献管理软件首个正式版本发放！**

**该软件目前适配Windows系统。**

**[立即下载最新版知序](https://github.com/CakeGeng/ZhiXu/releases/download/v1.0.0/Zhixu-Setup-1.1.0-x64.exe)**

**知序 v1.0.0 版本功能：**
1. 可以在“知识库”中导入文献、文件，并分类整理，支持创建子文件夹。
2. 可为文献添加pdf，可将文件作为附件绑定至某一文献或另一文件。
3. 阅读文献pdf及文件，并可为其添加标注和笔记（md格式）。
4. 解析文献pdf或文件（支持pdf、docx、md、txt、latex项目），解析后的文献或文件可以在阅读功能中实现快速翻译、语义分段翻译效果。
5. 以一篇文献为中心分析其引用关联链。
6. 内置编辑器，可进行latex项目、md文档写作。
7. 可创建ARXIV快递：选择感兴趣的领域，每天自动爬取ARXIV最新文献，并整理总结成报告。
8. AI助手：支持通过添加API key的方式使用AI助手，可以帮助执行软件的各种功能（例如搜索导入文献、添加pdf等）、分析文献进行研究。
9. 支持UI显示个性化调节。
注意：解析功能依赖于AI，因此需先添加API key（设置-模型设置）；分析引用链功能只能分析已解析文献之间的引用关联。
